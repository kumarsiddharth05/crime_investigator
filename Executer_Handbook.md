## 3. Completed & Verified Features

### A. Deterministic Rules Engine (`src/analysis/tier_a.py`)
- **Verified via:** `pytest tests/test_tier_a.py` (24 passed)
- Rules implemented:
  - `A1`: Gunshot residue present while weapon reported unfired.
  - `A2`: Forced entry evidence conflicting with deadbolt locked from inside.
  - `A3`: Exterior window broken inward without interior glass fragments.
  - `A4`: Blood spatter pattern conflicting with stated victim body position.
  - `A5`: Post-mortem lividity inconsistent with body discovery position.
  - `A6`: Entry timestamp occurs after exit timestamp.
  - `A7`: Event occurs before 911 call timestamp.
  - `A8`: Suspect alibi location timestamp conflicts with crime scene presence.

### B. Defense-in-Depth Validator & Reference Resolver (`src/analysis/validator.py`, `src/analysis/refs.py`)
- **Verified via:** `pytest tests/test_validator.py` (22 passed)
- Strict Draft-07 schema compliance on model outputs.
- Reference path resolution across nested dot-paths (`evidence.E1`, `notes.N1`, `photos.P1.d3`, `timeline.T1`).
- Deduplication against deterministic Tier A findings.
- Dismissal Guard: automatically rejects suggestions referencing explicitly dismissed evidence or investigative leads.
- Suspicious hallucination filtering on unresolvable entities.

### C. Pipeline Orchestrator & Semantic Gating (`src/analysis/pipeline.py`)
- **Verified via:** `pytest tests/test_pipeline.py` (24 passed)
- Context hash generation (SHA-256) for audit integrity.
- Semantic eligibility gate determines if case context contains necessary evidence types before firing LLM categories:
  - `spatial_inconsistency`: Requires multiple spatial observations.
  - `timeline_contradiction`: Requires multiple timestamped entries.
  - `contextual_contradiction`: Requires multiple corroborating/conflicting investigative notes.
- Immutable run audit record persistence to `runs/` (JSON).

### D. Multi-Provider LLM Client & Groq Rate Limiter (`src/llm/client.py`)
- **Verified via:** `pytest tests/test_client.py` (48 passed)
- **Groq Adapter (`_call_groq`):** Verified live end-to-end via Groq API on model `openai/gpt-oss-120b`.
- **`GroqRateLimiter`:**
  - Thread-safe token pacing (`threading.Lock`).
  - Default 20.0s cooldown between consecutive requests (configurable via `GROQ_COOLDOWN_SECONDS`).
  - Dynamic token bucket backoff when `x-ratelimit-remaining-tokens < 2500`.
  - HTTP 429 backoff extraction via `Retry-After` header and message regex parsing.
  - Cooldown wait time tracking (`total_wait_time`).
- Normalized envelope output (`LLMResponse`).
- Controlled retry layer: 1 immediate retry on HTTP 500/502/503/504; single repair retry on schema parse failure.

### E. Evaluation Harness & Atomic Checkpointing (`evaluate.py`)
- **Verified via:** `pytest tests/test_evaluate.py` (28 passed) and live run `eval_20261121_130243.json`
- Supports `dry_run`, `stub`, and `live` modes.
- Evaluates 13 benchmark fixtures against ground-truth expectations.
- Atomic checkpointing (`save_checkpoint` / `load_checkpoint`): saves per-category and per-fixture results to `reports/checkpoints/` using `.tmp` write + replace to survive interruptions.
- Resumes interrupted benchmarks without repeating completed API calls.
- Fingerprints evaluation runs (SHA-256) to prevent resuming mismatched provider/model/fixture configurations.
- Metric calculation: Tier A recall/precision, Tier B recall/precision, clean-case false positives, hallucination rate, provider latency, complete-case wall-clock latency, and total cooldown wait time.

### F. CLI Investigation Tool (`analyze.py`)
- **Verified via:** `tests/test_pipeline.py` CLI integration tests
- Runs complete analysis pipeline on case JSON files.
- Options: `--tier-a-only`, `--type`, `--all-types`, `--no-audit`, `--output`, `--provider`, `--model`.
- Terminal UI rendering via `rich` tables and panels.

## 5. Environment & Config Setup

### Environment Variables (`.env`)
Required variables for live execution (never commit secret values):
- `LLM_PROVIDER`: Provider name (`groq`, `gemini`, `openai`, `anthropic`, `openrouter`). Default for evaluation is `groq`.
- `LLM_MODEL`: Model identifier (e.g., `openai/gpt-oss-120b` for Groq, `gemini-3.8-flash` for Gemini).
- `GROQ_API_KEY`: Required when `LLM_PROVIDER=groq`.
- `GROQ_COOLDOWN_SECONDS`: (Optional) Float seconds between Groq requests (defaults to `20.0`). Set to `0.0` during mock tests.
- `GEMINI_API_KEY`: Required when `LLM_PROVIDER=gemini`.
- `OPENAI_API_KEY`: Required when `LLM_PROVIDER=openai`.
- `ANTHROPIC_API_KEY`: Required when `LLM_PROVIDER=anthropic`.
- `OPENROUTER_API_KEY`: Required when `LLM_PROVIDER=openrouter`.
